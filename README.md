## Эволюция проекта

### Переход от плоского списка ходов к системе лучей

На начальном этапе методы фигур возвращали плоский список координат возможных ходов.

Например, ладья генерировала все потенциальные клетки по четырём направлениям в одном списке.

В процессе реализации игровой логики обнаружилась архитектурная проблема: плоская структура не сохраняла информацию о направлениях движения фигуры. Это усложняло обработку препятствий, поскольку при встрече с другой фигурой необходимо прекращать движение только в соответствующем направлении, продолжая проверять остальные.

**Принятое решение:** перейти к представлению ходов в виде списка лучей (rays).

Теперь каждый луч представляет отдельное направление движения фигуры и содержит последовательность координат клеток в этом направлении.

Это позволяет:
- Независимо обрабатывать каждое направление.
- Прекращать движение по конкретному направлению при встрече с препятствием.
- Корректно реализовать перемещение ладьи, слона и ферзя.
- Сохранить единый подход к генерации ходов разных типов фигур.

Данный переход отражает развитие архитектуры проекта по мере выявления ограничений первоначальной реализации.
